## 🤖 Why contribute here?

Unlike other repositories, this project is managed by **Smart Automation**:
- **⚡ Instant Assignment:** Comment "assign me", and the bot assigns you immediately.
- **🤖 AI Code Review:** Our bot checks your code instantly for errors.
- **🚀 Auto-Merge:** If your changes are correct, your PR is merged automatically!
- **🔄 Infinite Cycle:** As soon as one slot closes, a new issue opens for the next person.

## 🛠️ How to Contribute (The AI Way)

Follow these steps exactly to see the magic happen:

### Step 1: Claim an Issue 🙋‍♂️
Go to the [**Issues Tab**](../../issues). Look for an open issue titled **"Contribution Slot"**.
- Open the issue.
- Comment: `Assign me`
- **Wait 5 seconds.** The bot will reply and assign the issue to you!

### Step 2: Fork & Clone 🍴
Click the **Fork** button (top right) to create a copy of this repository to your account.

### Step 3: Add Your Name ✍️
1. Go to the `contributors/` folder.
2. Open the file `README.md`.
3. Add your name and GitHub profile link to the list.
   ```markdown
   - [Your Name](https://github.com/your-username)
   ```
      *(⚠️ **Warning:** Do not touch any other file, or the AI will reject your PR!)*

### Step 4: Submit Pull Request (PR) 🔀
1. Create a Pull Request from your fork to the `main` branch of this repository.
2. **CRITICAL:** In the PR description, you **MUST** write:
   > `Closes #<issue_number>`
   
   *(Replace `<issue_number>` with the issue number you were assigned, e.g., Closes #15)*.
